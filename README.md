# 🎮 الشريط المفقود - The Lost Tape

لعبة ويب تفاعلية تجمع بين الهزل والغموض والجدية. تعتمد على قصة غامضة حيث يتعاون اللاعب مع راوٍ ساخر لإصلاح موقع ويب معطوب.

## 🌍 اللغات المدعومة
- العربية (اللغة الأساسية)
- الإنجليزية
- الفرنسية

## 🎯 مميزات اللعبة
- قصة غامضة تفاعلية
- راوٍ ذو شخصية فكاهية
- ألغاز متنوعة (سحب، نقر، حوار)
- واجهة مستخدم متعددة اللغات
- تصميم متجاوب يعمل على جميع الأجهزة
